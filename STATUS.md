# Status

* Done and tested: workspace manager (daemon, CLI, API v2), headless labwc workspaces with GPU acceleration on NVIDIA, MCP server, GTK4 viewer with take-over, per-agent opt-in integrations, installers, unit tests (107) and real integration tests (workspaces 17, reliability 21, sandbox 12, agent CLIs 2, not re-run on the security branch), measurements, docs.
* Done and tested in isolation only: GNOME Shell extension (headless isolated shell, stand-ins for daemon/viewer).
* Not done: see `docs/limitations.md` and `docs/testing.md` ("Not tested").
* Security branch (`feat/security`): API v2 with per-workspace credentials, human-only grants, routing identity checks, optional bubblewrap sandbox, reliability tests. See `docs/security-model.md`.
* Browsers/compat branch (`feat/browsers-compat`): browser discovery and launch (throwaway, agent and human-authorised profile copies through the grants layer), one merged Wayland + private-XWayland window list with move/resize, per-workspace private PipeWire audio with capture and human-only host routing, application compatibility matrix run for real. See `docs/browsers.md`, `docs/windows.md`, `docs/audio.md`, `docs/compatibility.md`. Not tested: any real browser profile of the user, real speakers.
* Agent integration (branch `feat/agents-integration`): Claude Code (Haiku 5.5) and Codex (GPT-6-Luna) were run with real models and ordinary prompts and completed browser, text editor, file manager, screenshot and two-app tasks inside workspaces they created for themselves, also two at the same time and without a viewer. Antigravity is blocked (login lives in the desktop keyring) and Hermes could not be run with a model (none loaded on the Spark router). Results and limits: `docs/compatibility-matrix.md`.
